# Trans Fort Soluções — Landing Page

Landing page comercial de alta conversão para a plataforma **Trans Fort Soluções**, sistema de gestão para transportadoras, empresas de mudanças e logística.

## Stack

- React 19
- Vite 6
- Tailwind CSS 4
- Lucide React
- TypeScript

## Desenvolvimento

```bash
npm install
npm run dev
```

Acesse [http://localhost:5173](http://localhost:5173).

## Build

```bash
npm run build
npm run preview
```

## Configuração

Edite `src/config/site.ts` para alterar:

- Número do WhatsApp
- E-mail de contato
- Mensagens padrão dos CTAs
- Nome e tagline da marca

## Deploy

Após o build, publique a pasta `dist/` em qualquer hospedagem estática (Vercel, Netlify, Cloudflare Pages, etc.).
